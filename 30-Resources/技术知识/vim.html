Vim 编辑器使用指南

概述

Vim 是一个高度可配置的文本编辑器，效率提升来自其模式编辑设计。

模式

四种基本模式

  1. Normal 模式：浏览、操作文本（默认）
  2. Insert 模式：输入文本（i, a）
  3. Visual 模式：选择文本（v, V）
  4. Command 模式：执行命令（:）

基础操作

移动

按键功能
h j k l左下上右
w / b下/上一个单词
0 / $行首/行尾
gg / G文件首/尾
<C-f> / <C-b>下/上一页

编辑

按键功能
i / a在光标前/后插入
o / O在下/上行新建
dd删除行
yy复制行
p / P在后/前粘贴
u / <C-r>撤销/重做

Visual 模式

按键功能
v字符选择
V行选择
<C-v>块选择
o跳到选择另一端
