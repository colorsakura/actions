模块概述

类与对象

5. Mixin 机制

Mixin 机制

Mixin 机制

概述

Mixin 是 Dart 中一种强大的代码复用机制，允许在不使用继承的情况下，在多个类层次结构中复用代码。Mixin 是 Dart 区别于其他语言的重要特性之一。

Mixin 基本概念

Mixin 是一种可以在多个类层次结构中复用的类。它提供了一种灵活的方式来组合功能。

OOP 设计原则

设计原则

  1. 单一职责原则：一个类只负责一件事
  2. 开闭原则：对扩展开放，对修改关闭
  3. 里氏替换原则：子类可以替换父类
  4. 接口隔离原则：不应强迫实现不需要的接口
  5. 依赖倒置原则：依赖抽象而非具体

常见误区

注意事项

  1. Dart 没有真正的接口：每个类都可以作为接口，但使用 interface 和 final 修饰符更清晰
  2. Mixin 不是继承：Mixin 是代码复用机制，不建立 “is-a” 关系
  3. 构造函数不能继承：子类不会继承父类的构造函数
  4. @override 不是必须的：但强烈建议使用，有助于代码检查
