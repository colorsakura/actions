Dart 核心库篇

模块概述

Dart 提供了丰富的核心库（core libraries），本篇介绍常用的集合操作、字符串处理、日期时间等核心库的使用方法。

学习目标

完成本篇学习后，你将能够：

  • 熟练使用 List、Set、Map 进行数据操作
  • 掌握字符串的各种处理方法
  • 理解日期时间的处理
  • 了解数学运算库的使用

3. Map 操作

Map 操作

Map 操作

概述

Map 是 Dart 中存储键值对的数据结构，提供高效的查找、插入和删除操作，基于哈希表实现。

Map 的特点

键值对：每个元素由 key 和 value 组成

键的唯一性：Map 中的 key 必须唯一，重复的 key 会覆盖旧值

快速查找：基于哈希表实现，平均查找时间复杂度 O(1)

Map vs List 查找性能对比

操作ListMap
按索引查找O(1)不支持
按值查找O(n)O(1)
插入/删除O(n)O(1)
适用场景有序数据、索引访问键值对、快速查找

集合操作最佳实践

集合使用建议

  1. 选择合适的集合类型：List 有序可重复，Set 无序不重复，Map 键值对
  2. 优先使用不可变集合：使用 List.unmodifiable() 等
  3. 链式调用：使用 map/where/reduce 等方法进行链式操作
  4. 避免在循环中修改集合：可能导致 ConcurrentModificationError
  5. 考虑性能：List 的随机访问是 O(1)，Set 的查找是 O(1)

字符串处理建议

字符串建议

  1. 使用字符串插值：比 + 连接更高效易读
  2. 大字符串使用 StringBuffer：避免创建多个临时对象
  3. 正则表达式预编译：重复使用时先编译
  4. 注意编码：Dart 默认使用 UTF-16

常见误区

注意事项

  1. List 的 sort 方法会修改原列表：如需保留原列表，先拷贝
  2. where 返回 Iterable：需要调用 toList() 转换为 List
  3. DateTime 比较使用 isAtSameMomentAs：不要用 == 操作符
  4. 随机数需要导入 dart:math：Random 类在 math 库中
  5. Duration 不能表示月份：因为月份天数不固定
