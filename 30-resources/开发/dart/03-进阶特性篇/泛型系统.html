泛型系统

概述

泛型（Generics）是 Dart 中强大的类型安全机制，允许编写灵活、可复用的代码，同时保持编译时类型检查。泛型在集合、API 设计和类型安全的代码复用中扮演重要角色。

性能考虑

[!info> 泛型性能

  • Dart 在运行时保留了泛型信息（与 Java 不同）
  • 泛型不会带来性能损失
  • 编译时进行类型检查，提高代码质量
  • 使用泛型可以避免运行时类型转换
