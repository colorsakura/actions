一、Go Router 简介

1.1 什么是 Go Router？

Go Router 是 Flutter 官方团队维护的声明式路由包，提供：

核心特性

  • ✅ 声明式路由：用代码定义路由，清晰易维护
  • ✅ 深度链接：支持通过 URL 直接访问应用内任何页面
  • ✅ 类型安全：编译时检查路由参数
  • ✅ 数据驱动：路由可以携带数据
  • ✅ Web 支持：完美支持浏览器的前进/后退
  • ✅ 动画支持：自定义页面切换动画

1.2 为什么选择 Go Router？

声明式❌❌✅
深度链接❌⚠️ 困难✅ 原生支持

类型安全❌❌✅
数据传递⚠️ 手动⚠️ 手动✅ 自动
官方维护✅✅✅ 推荐使用

十、StatefulShellRoute（17.x 新特性）

10.1 什么是 StatefulShellRoute？

生活比喻

StatefulShellRoute 是 ShellRoute 的增强版，可以为每个分支（Branch）维护独立的 Navigator 和状态。

典型场景： 底部导航应用，切换 Tab 时保持各 Tab 的页面状态（如滚动位置、表单内容等）。

与 ShellRoute 的区别：

特性ShellRouteStatefulShellRoute
独立 Navigator❌ 共享✅ 每个分支独立
状态保持❌ 切换即销毁✅ 自动保持
预加载❌ 不支持✅ 支持
使用场景简单底部导航复杂 Tab 应用

10.2 创建底部导航应用（状态保持）

关键特性：

  • ✅ 切换 Tab 时页面状态完全保持
  • ✅ 支持预加载（preload: true）
  • ✅ 每个分支有独立的导航历史栈
  • ✅ 支持嵌套路由且保持状态

10.3 预加载功能

预加载优化

预加载可以在应用启动时初始化分支，改善首次访问的用户体验。

适用场景：

  • 页面初始化耗时长
  • 需要从网络加载数据
  • 复杂的页面构建逻辑

10.4 状态保持示例

使用 StatefulShellRoute 后：

  • 切换到其他 Tab 再返回，滚动位置保持
  • 计数器状态保持
  • 表单输入内容保持

十三、迁移指南

13.1 从 16.x 迁移到 17.x

重大变更

Go Router 17.0 引入了一些重要的行为变化和新增功能。

主要变更：

  1. ShellRoute 导航变化通知
  1. onEnter 回调新增
  1. redirect 回调中的 context 支持
  1. GoRouter.of(context) 在 redirect 中的访问
  1. StatefulShellRoute 预加载
  1. caseSensitive 行为变更
  1. Fragment 支持

13.2 从 15.x 迁移到 16.x

架构优化

16.0 版本主要是内部架构优化，API 保持高度兼容。

注意事项：

  • 大部分代码无需修改
  • 建议测试所有导航流程
  • 检查第三方路由库兼容性

13.3 从 14.x 迁移到 15.x

重大变更

Go Router 15.0 包含破坏性变更，特别是 extra 的传递方式。

主要变更：

  1. Extra 数据传递
  1. 路由信息获取

13.4 从 Navigator 1.0 迁移

逐步迁移

可以在同一应用中同时使用 Navigator 和 GoRouter，逐步迁移。

迁移对照表：

Navigator 1.0GoRouter
Navigator.pushNamed('/route')context.go('/route')
Navigator.pop()context.pop()
Navigator.pushReplacementNamed('/route')context.go('/route')
Navigator.popUntil()context.popUntil()

十五、常见问题

15.1 浏览器地址栏不更新

问题： 使用 context.push() 导致地址栏不更新。

解决： 使用 GoRouter 的导航方法。

15.2 路由参数中文乱码

问题： URL 中的中文显示为编码。

解决： GoRouter 15.x 自动处理 UTF-8 编码。

15.3 热重载问题

问题： 频繁路由导致动画卡顿。

解决： 使用 pageBuilder 替代 builder。
