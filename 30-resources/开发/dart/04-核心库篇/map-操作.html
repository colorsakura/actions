Map 操作

概述

Map 是 Dart 中存储键值对的数据结构，提供高效的查找、插入和删除操作，基于哈希表实现。

Map 的特点

键值对：每个元素由 key 和 value 组成

键的唯一性：Map 中的 key 必须唯一，重复的 key 会覆盖旧值

快速查找：基于哈希表实现，平均查找时间复杂度 O(1)

Map vs List 查找性能对比

操作ListMap
按索引查找O(1)不支持
按值查找O(n)O(1)
插入/删除O(n)O(1)
适用场景有序数据、索引访问键值对、快速查找

Map 的性能考虑

查找性能

内存占用

Map 比同类数据的 List 占用更多内存，但提供了更快的查找性能。根据实际场景选择：

  • 需要按键快速查找 → 使用 Map
  • 需要保持顺序且数据量小 → 使用 List
